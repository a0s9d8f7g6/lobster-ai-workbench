📲 安装到手机主屏

安装后可像 App 一样从桌面打开，离线也能用，数据存本机。分两步：先在手机浏览器打开本页，再按下方操作。

🍎 iPhone（Safari）

  1. 用 Safari 打开本页链接（微信内请先「在浏览器中打开」）
  2. 点底部地址栏，展开后点右侧 「⬆️ 分享」 按钮
  3. 下滑找到 「添加到主屏幕」 → 右上角「添加」

🤖 安卓（Chrome / Edge）

  1. 用 Chrome 或 Edge 打开本页（QQ、UC、OPPO/Vivo 自带浏览器多不支持）
  2. 地址栏右侧若出现 「安装」 图标，直接点它
  3. 或点右上角 「⋮」 → 「安装应用」/「添加到主屏幕」
⚠ 微信、QQ 浏览器、OPPO/Vivo 自带浏览器均不支持 PWA 安装，请务必用 Safari / Chrome / Edge。

⚙ AI 设置

填入 OpenAI 兼容接口的 API（DeepSeek / 通义 / 智谱 / OpenAI / 本地 Ollama 均可）。Key 只存在你本机浏览器，绝不外传。
