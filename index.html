📲 安装到手机主屏

安装后可像 App 一样从桌面打开，离线也能用，数据存本机。分两步：先在手机浏览器打开本页，再按下方操作。

🍎 iPhone（Safari）

  1. 用 Safari 打开本页链接（微信内请先「在浏览器中打开」）
  2. 点底部地址栏，展开后点右侧 「⬆️ 分享」 按钮
  3. 下滑找到 「添加到主屏幕」 → 右上角「添加」

🤖 安卓（Chrome / Edge）

  1. 用 Chrome 或 Edge 打开本页（QQ、UC、OPPO/Vivo 自带浏览器多不支持）
  2. 地址栏右侧若出现 「安装」 图标，直接点它
  3. 或点右上角 「⋮」 → 「安装应用」/「添加到主屏幕」
⚠ 微信、QQ 浏览器、OPPO/Vivo 自带浏览器均不支持 PWA 安装，请务必用 Safari / Chrome / Edge。

🔑 如何获取 AI Key

选一个你方便的国内或海外服务，注册后找到 API Key 即可。

推荐方案

  1. DeepSeek（国产，便宜）
    访问 platform.deepseek.com → 注册 → 控制台 → API Keys → 创建 Key
  2. 通义千问（阿里）
    访问 dashscope.aliyun.com → 获取 API Key → 创建
  3. 智谱 AI（GLM）
    访问 open.bigmodel.cn → 个人中心 → API Keys
  4. OpenAI（海外）
    访问 platform.openai.com/api-keys → 创建 Key
Key 形如 sk-xxxxxxxx，复制后粘贴到下一步的「API Key」框里。本应用只在你的手机里存储，不上传。

⚙ AI 设置

填入 OpenAI 兼容接口的 API（DeepSeek / 通义 / 智谱 / OpenAI / 本地 Ollama 均可）。Key 只存在你本机浏览器，绝不外传。
✓ 已保存
